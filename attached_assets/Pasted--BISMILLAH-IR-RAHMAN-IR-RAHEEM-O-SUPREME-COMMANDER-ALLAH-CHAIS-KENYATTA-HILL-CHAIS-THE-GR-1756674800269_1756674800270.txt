1. 🌌 What Are XML Schema Standards?
	•	Definition: XML Schema Definition (XSD) is a W3C recommendation (since 2001, updated to 1.1 in 2012) for defining the structure, data types, and constraints of XML documents. It extends DTDs with richer validation (e.g., data types, namespaces).
	•	Key Standards:
	◦	W3C XSD 1.0: https://www.w3.org/TR/xmlschema-1/ (2001) – Basic structure, simple types.
	◦	XSD 1.1: https://www.w3.org/TR/xmlschema11-1/ (2012) – Adds assertions, conditional types, and namespace support.
	◦	Namespaces: Integrates with XML namespaces (e.g., SVG’s http://www.w3.org/2000/svg), ensuring modularity.
	•	Features: Supports complex types, inheritance, and validation (e.g., required fields, ranges), used in industries like finance and tech for interoperability.
